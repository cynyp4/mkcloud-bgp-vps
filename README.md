## 都叫"BGP"，直连和绕路差在哪

差在进出内地走不走运营商自家的骨干网。大陆优化 BGP 指电信、联通、移动三网各自直连香港机房；国际 BGP 则借助 NTT、Level3 这类国际中转商，价格便宜，但路由绕、延迟高、晚高峰抖动大。

这层区别商家页面往往不会主动写，好在验证不复杂：拿到测试 IP 后跑一次 traceroute 或 mtr，对照三个特征。

- 电信方向看有没有 59.43 开头的节点（CN2）或 202.97 的 163 骨干，直连时出香港没几跳就进内地；
- 联通方向看 AS4837（219.158 开头的节点）；
- 移动方向看 CMI。反过来，路由里出现 NTT、Level3 这些国际中转商，或者先去日本、新加坡甚至美国兜一圈再回内地，基本可以判定是绕路线路。

## 常见问题

**香港 BGP VPS 需要备案吗？**
不需要。香港机房不受内地 ICP 备案约束，开通后把域名解析过去即可使用，新站上线不用等审核。

**延迟多少算正常？**
直连线路国内访问普遍在 5–40ms，全国平均能压到 45ms 以内。测出来 60ms 以上、晚高峰明显抖动，大概率绕了国际中转。

**BGP 和 CN2 GIA 怎么选？**
BGP 是一个 IP 同时接入电信、联通、移动多线并自动选路，三网访客都照顾到；CN2 GIA 是电信单家的高端线路，电信体验好，联通移动用户未必受益。访客三网混杂选 BGP；用户几乎全是电信且预算充足时，再考虑 CN2 GIA。

**IP 被封了怎么办？**
多数商家支持付费更换 IP，具体政策和费用以商家条款为准。日常业务内容合规，是降低 IP 风险最有效的一件事。
